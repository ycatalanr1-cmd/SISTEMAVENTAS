# ¡Bienvenido a SistemaVentas!

Este manual es una guía para el uso del sistema SistemaVentas. Su propósito es explicar de manera clara las principales funciones de la aplicación y los procedimientos para realizar la gestión de compras.

### ¿Qué es SistemaVentas?

SistemaVentas es una aplicación web para facilitar el seguimiento y el desarrollo de los procesos de compra de una empresa. Se accede desde el navegador mediante un enlace, sin necesidad de instalar programas en la computadora. A través del sistema es posible registrar pedidos internos, gestionar órdenes de compra, recibir ofertas de proveedores, realizar adjudicaciones y generar reportes en formato PDF.

### ¿Cómo está organizado este manual?

El manual está dividido en secciones que corresponden a las funciones del sistema. Cada apartado describe las opciones disponibles y explica los procedimientos paso a paso, indicando el resultado esperado en la aplicación.

Se recomienda seguir las secciones en orden la primera vez que se use el sistema. Sin embargo, quien ya conoce la aplicación puede ir directamente a la sección que necesite.

### Consideraciones generales

* Las opciones que se muestran en el menú dependen del rol del usuario: Administrador del Sistema, Gestor de Compras, Administrador de Proveedor, Auditor o Creador de Pedidos.
* Las cuentas de prueba se encuentran en la sección "Iniciar sesión en la aplicación".
* Para resolver dudas rápidas, se puede consultar al asistente del manual.
