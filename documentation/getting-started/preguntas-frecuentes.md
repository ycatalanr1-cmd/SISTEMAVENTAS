# Preguntas Frecuentes

#### Cómo cambiar la contraseña

1. Hacer clic en el nombre del usuario, en la esquina superior derecha, y abrir el perfil.&#x20;
2. En el recuadro "Cambiar Contraseña", escribir la contraseña actual.
3. Escribir la nueva contraseña y repetirla en "Confirmar nueva contraseña".
4. Hacer clic en el botón para guardar el cambio.

Los campos con asterisco (\*) son obligatorios. El ícono del ojo, a la derecha de cada campo, permite mostrar u ocultar lo que se escribe.

#### ¿Cómo cambio entre Azure SQL y SQL Server Local?

1. Cerrar la aplicación.
2. Abrir nuevamente SistemaVentas.
3. En la pantalla de selección de base de datos, elegir la opción deseada.
4. Continuar con el inicio de sesión.

#### ¿Qué pasa si se pierde la conexión a internet?

* **Azure SQL:** se necesita conexión a internet para acceder a la base de datos en la nube.
* **SQL Server Local:** la aplicación puede continuar funcionando sin internet, siempre que el servidor local esté disponible.

#### ¿Por qué mi pedido no aparece para los proveedores?

Los proveedores solamente pueden visualizar los pedidos que corresponden a los rubros que tienen asociados. Si los artículos del pedido pertenecen a un rubro diferente, no aparecerán en su listado.

#### ¿Puedo eliminar un pedido adjudicado?

No. Los pedidos que ya fueron adjudicados no se pueden eliminar. Según las funciones del sistema, solamente se permite su edición cuando corresponda.

#### ¿Cómo puedo consultar mis ofertas?

* **Como proveedor:** ingresar al menú **"Mis Ofertas"** para consultar las ofertas registradas.
* **Como Gestor de Compras:** ingresar al módulo correspondiente a las ofertas dentro de las opciones de compras.

#### ¿Dónde se generan los reportes?

Los reportes se generan desde el backend de la aplicación, desarrollado en .NET, utilizando la biblioteca **QuestPDF**. Posteriormente, el usuario puede visualizarlos y descargarlos en formato PDF.

### Soporte

Si se presenta algún problema al utilizar el sistema, se recomienda seguir estos pasos:

1. Consultar este manual para revisar el procedimiento correspondiente.
2. Revisar la sección de **Preguntas Frecuentes**.
3. Si el problema continúa, contactar al administrador del sistema para recibir asistencia.
