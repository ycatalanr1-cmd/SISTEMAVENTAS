# Roles y Funciones

El sistema cuenta con cinco roles: Administrador, Gestor de Compras, Administrador de Proveedor, Auditor y Creador de Pedidos. Cada rol visualiza únicamente las opciones y funciones que tiene autorizadas, por lo que al iniciar sesión el menú de navegación cambia según la cuenta utilizada.

### Administrador

El Administrador es el rol con mayor alcance dentro del sistema. Tiene acceso a todos los módulos y es el responsable de administrar usuarios, catálogos y configuraciones generales.

#### Menú del Administrador

| Opción    | Descripción                                                                                                    |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| Dashboard | Pantalla de resumen con los totales y gráficos del sistema                                                     |
| Artículos | Consulta y administración de los artículos registrados                                                         |
| Usuarios  | Administración de las cuentas de usuario                                                                       |
| Catálogos | Despliega las opciones: Rubros, Categorías, Unidades, Tipos de orden, Departamentos,  Sucursales y Proveedores |
| Compras   | Despliega las opciones: Pedidos interos, Órdenes de compras, Adjudicaciones                                    |
| Admin     | Despliega las opciones: Roles, Reportes y Auditoría                                                            |

Las opciones Catálogos, Compras y Admin son menús desplegables. Para ver su contenido, hacer clic sobre ellas.

#### Funciones del Administrador

* Crear, editar y eliminar usuarios.
* Gestionar los catálogos (rubros, categorías y unidades).
* Aprobar órdenes de compra.
* Adjudicar pedidos.
* Consultar todos los reportes.

#### Cómo realizar las funciones principales

**Administrar usuarios:** ingresar a la opción "Usuarios" del menú. Desde esa pantalla se pueden crear cuentas nuevas, modificar los datos de las existentes y eliminar las que ya no se necesiten.
