# Auditor

El Auditor es el rol de supervisión del sistema. Su trabajo es revisar lo que ocurre, no modificarlo: consulta los reportes y el historial de eventos para verificar que el proceso de compra se esté realizando correctamente.

#### Cómo ingresar con esta cuenta

Para trabajar con este rol se inicia sesión con una cuenta de Auditor. En las cuentas de prueba corresponde a Juan Pérez:

1. Abrir la aplicación SistemaVentas.
2. Escribir el correo electrónico y la contraseña del Auditor, que se encuentran en la tabla de credenciales de prueba.
3. Hacer clic en el botón "Iniciar sesión".

Al entrar, el sistema abre directamente la pantalla "Reportes y Análisis". En la esquina superior derecha aparece el nombre del usuario y su rol.
