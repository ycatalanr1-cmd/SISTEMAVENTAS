# Reportes

El sistema cuenta con diferentes reportes que permiten consultar información sobre las compras, proveedores, órdenes y pedidos registrados. Estos documentos se pueden visualizar y descargar en formato PDF.

#### Cómo generar un reporte

1. Se iniciar sesión con una cuenta que tenga permisos para consultar reportes.
2. Ingresar a la opción **"Reportes"** desde el menú correspondiente.
3. Seleccionar el reporte que se desea consultar.
4. Esperar a que el sistema genere el documento PDF.
5. Utilizar los botones disponibles según sea necesario:
   * **Recargar:** vuelve a generar el reporte.
   * **Descargar:** permite guardar el documento PDF en la computadora.
