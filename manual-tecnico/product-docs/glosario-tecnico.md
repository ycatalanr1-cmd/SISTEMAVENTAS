# GLOSARIO TÉCNICO

## 22. Glosario técnico

| Término               | Definición                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| API REST              | Interfaz HTTP que permite a Angular consultar y modificar recursos del sistema.                |
| Angular               | Framework utilizado para construir la interfaz web.                                            |
| ASP.NET Core          | Framework de .NET utilizado para implementar la API.                                           |
| DTO                   | Objeto de transferencia de datos utilizado para recibir o devolver información.                |
| Entity Framework Core | ORM que permite trabajar con entidades y consultas relacionales desde C#.                      |
| JWT                   | Token firmado que contiene la identidad y los claims del usuario autenticado.                  |
| BCrypt                | Algoritmo utilizado para verificar contraseñas almacenadas como hash.                          |
| Repositorio           | Componente que encapsula operaciones de acceso a datos.                                        |
| Servicio              | Componente que coordina operaciones y reglas de negocio.                                       |
| Migración             | Cambio versionado del esquema de base de datos administrado por Entity Framework Core.         |
| RabbitMQ              | Broker que recibe y distribuye mensajes entre productores y consumidores.                      |
| MassTransit           | Biblioteca que facilita la publicación y consumo de eventos.                                   |
| MongoDB               | Base de datos documental utilizada para almacenar historiales.                                 |
| QuestPDF              | Biblioteca .NET utilizada para generar archivos PDF.                                           |
| CORS                  | Política que controla qué orígenes pueden realizar solicitudes al servidor.                    |
| Guard                 | Función de Angular que controla la navegación a rutas según condiciones de acceso.             |
| Claim                 | Dato incluido en el token que representa información del usuario, como su rol o identificador. |
